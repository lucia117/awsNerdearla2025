# 🌱 EcoCalc - Calculadora de Huella de Carbono Personal

Una aplicación web interactiva que calcula tu huella de carbono personal y te da consejos personalizados para reducirla. Creada para el **Desafío 3 de Nerdearla 2025** usando **Amazon Q Developer**.

## 🚀 Demo en Vivo

Abre `index.html` en tu navegador para probar la aplicación.

## ✨ Características

- **Cálculo Preciso**: Basado en factores de emisión reales
- **Interfaz Moderna**: Inspirada en Nerdearla y AWS Builder
- **Tips Personalizados**: Consejos específicos según tu huella
- **Responsive**: Funciona perfecto en móviles y desktop
- **Animaciones Suaves**: Experiencia de usuario fluida

## 🛠️ Tecnologías

- **HTML5**: Estructura semántica
- **CSS3**: Gradientes, animaciones, responsive design
- **JavaScript ES6+**: Clases, cálculos dinámicos
- **Google Fonts**: Tipografía Inter

## 📊 Cómo Funciona

1. **Transporte**: Calcula emisiones de auto y vuelos
2. **Hogar**: Considera electricidad y tipo de calefacción
3. **Alimentación**: Evalúa consumo de carne
4. **Resultado**: Muestra total en toneladas CO₂ anuales
5. **Comparación**: Te compara con el promedio mundial
6. **Tips**: Consejos personalizados para reducir tu huella

## 🎯 Factores de Emisión Utilizados

- **Auto**: 0.2 kg CO₂ por km
- **Vuelo**: 1000 kg CO₂ por vuelo promedio
- **Electricidad**: 0.5 kg CO₂ por kWh
- **Carne**: 15 kg CO₂ por comida con carne
